## Objective
Create the project skeleton: a Vite React TypeScript client, an Express TypeScript server with a health endpoint, and shared tooling — nothing else.

## Prerequisites
None. The repo currently contains only `PLAN.md`, `docs/`, `tasks/`, and `content/`. Do not modify those.

## Context
This is a local, single-user learning app. Client (port 5173) talks to server (port 4000) through a Vite dev proxy, so client code always uses relative `/api/...` URLs. No database work in this task.

## Files to create

```
.gitignore
README.md
client/  (generated by Vite, then edited)
  package.json, vite.config.ts, tailwind.config.js, postcss.config.js,
  index.html, src/main.tsx, src/App.tsx, src/index.css
server/
  package.json, tsconfig.json, src/index.ts
```

## Steps

1. Root `.gitignore`:
   ```
   node_modules/
   dist/
   vendor/
   server/data/*.db
   server/data/*.db-*
   ```
2. Root `README.md`: project title, one-paragraph description, and:
   ```
   ## Run
   1. cd server && npm install && npm run dev   # API on :4000
   2. cd client && npm install && npm run dev   # UI on :5173
   See PLAN.md for the full plan.
   ```
3. Client: `npm create vite@latest client -- --template react-ts`, then add deps:
   ```
   npm i @xyflow/react zustand react-router-dom react-markdown remark-gfm lucide-react
   npm i -D tailwindcss@3 postcss autoprefixer && npx tailwindcss init -p
   ```
   - `tailwind.config.js` content: `["./index.html", "./src/**/*.{ts,tsx}"]`
   - `src/index.css`: the three `@tailwind` directives only.
   - `vite.config.ts`: add
     ```ts
     server: { proxy: { '/api': 'http://localhost:4000' } }
     ```
   - `src/App.tsx`: replace demo content with a centered `<h1>Interactive System Design</h1>` and a paragraph that fetches `GET /api/health` on mount and shows `API: ok` or `API: unreachable`.
4. Server package:
   - `server/package.json` deps: `express@4`, `cors`, `zod`, `better-sqlite3`; devDeps: `typescript`, `tsx`, `@types/express`, `@types/cors`, `@types/better-sqlite3`, `@types/node`.
   - scripts: `"dev": "tsx watch src/index.ts"`, `"build": "tsc"`, `"start": "node dist/index.js"`.
   - `server/tsconfig.json`: `strict: true`, `outDir: "dist"`, `module: "commonjs"`, `target: "ES2022"`, `esModuleInterop: true`.
   - `server/src/index.ts`:
     ```ts
     import express from 'express';
     import cors from 'cors';

     const app = express();
     app.use(cors());
     app.use(express.json());

     app.get('/api/health', (_req, res) => res.json({ status: 'ok' }));

     const PORT = 4000;
     app.listen(PORT, () => console.log(`API listening on http://localhost:${PORT}`));
     ```

## Acceptance criteria
- [ ] `cd server && npm install && npm run dev` starts without errors; `curl http://localhost:4000/api/health` returns `{"status":"ok"}`.
- [ ] `cd client && npm install && npm run dev` serves the app on :5173 showing the title and `API: ok` while the server runs.
- [ ] `cd client && npx tsc --noEmit` and `cd server && npx tsc --noEmit` both pass.
- [ ] `git status` shows no `node_modules/` or `*.db` files tracked.

## Out of scope
Database, routes beyond `/api/health`, any UI beyond the health check, ESLint/Prettier config, tests.
